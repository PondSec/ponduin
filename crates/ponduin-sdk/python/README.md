# ponduin-sdk

Python bindings for the Ponduin SDK.

This package is generated from the Rust `ponduin-sdk` crate using UniFFI.

## Build a local wheel

From the repository root:

```bash
just --justfile crates/ponduin-sdk/justfile python-wheel
```

The wheel is written to `crates/ponduin-sdk/python/dist/`.
